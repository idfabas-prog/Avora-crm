# Operations Handbook

## Daily

- Review health and readiness.
- Review failed jobs and dead-letter records.
- Review security events.
- Review accounting exceptions and campaign failures.

## Weekly

- Review access report and high-risk permissions.
- Review backup status.
- Review launch readiness warnings.
- Confirm live gates match current approvals.

## Monthly

- Run staging restore drill when required by launch policy.
- Review inactive users.
- Review storage policies and signed URL lifetimes.
- Review dependency audit findings.

No report in Avora should be treated as HIPAA, SOC 2, PCI, GDPR, or other certification evidence without professional review.
