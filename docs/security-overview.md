# Avora Security Overview

Avora uses Supabase Auth, RLS, server-side authorization helpers, scoped route handlers, provider webhook signatures, and explicit live-write gates.

Phase 20 adds:

- centralized environment validation
- public env and secret scanning foundation
- request rate limiting foundation
- protected readiness endpoint
- security headers
- structured redacted logging
- error monitoring abstraction
- feature gates for live integrations
- system settings for maintenance/read-only modes
- launch readiness and security dashboards

This is readiness work only. It is not a certification claim.
